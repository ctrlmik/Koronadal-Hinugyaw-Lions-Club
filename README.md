# Koronadal Hinugyaw Lions Club — Club Manager

A single-page web app for the Hinugyaw Lions Club to record members, dues, billing,
payments/receipts, invoices, expenses, activities/service projects, and minutes of meetings.

## Files
- `index.html` — the whole app (open it directly in a browser, or host it as a static site).

## Notes
This copy was exported from a Claude.ai artifact. Some features (shared multi-user data
sync, member sign-in, and file uploads) only work when the file is running as a published
Claude artifact — opening `index.html` on its own will run it in local/offline mode using
your browser's storage instead.
